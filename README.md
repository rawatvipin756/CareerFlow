# CareerFlow 🚀

CareerFlow is a career management platform designed to help students and job seekers organize their internship applications, manage interview schedules, and track their career preparation journey in one place.

It provides a centralized dashboard to manage career opportunities and stay organized throughout the job-hunting process.

## 🌐 Live Demo

[View Live Demo](https://careerflow-yw0a.onrender.com/)

## ✨ Features

- **User Authentication:** Secure user registration and login.
- **Dashboard:** Get an overview of your career activities.
- **Internship Management:** Organize and track internship applications.
- **Interview Tracking:** Manage interview details and schedules.
- **Application Management:** Keep track of application progress.
- **Centralized Platform:** Manage career-related activities in one place.
- **Responsive Interface:** User-friendly experience across different devices.

## ⚙️ Installation & Setup

### 1. Clone the repository

```bash
git clone YOUR_GITHUB_REPOSITORY_URL
```

### 2. Navigate to the project directory

```bash
cd CareerFlow
```

### 3. Setup Backend

```bash
cd Backend
npm install
```

Create a `.env` file in the Backend directory and configure:

```env
PORT=5000
MONGO_URI=your_mongodb_connection_string
JWT_SECRET=your_jwt_secret
```

Start the backend:

```bash
npm run dev
```

### 4. Setup Frontend

Open another terminal:

```bash
cd Frontend
npm install
npm run dev
```

Open the local URL provided by Vite in your browser.
